# Cómo aportar

1. Crea una rama desde `main` con el prefijo que corresponda: `feature/`, `fix/` o `docs/`.
2. Haz tus cambios y pruébalos con datos sintéticos o de prueba.
3. Abre un Pull Request y llena la plantilla.
4. Otro miembro del equipo lo revisa antes del merge.
5. Después del merge, borra la rama.

Nunca subas datos de pacientes, contraseñas ni tokens.
